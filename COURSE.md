# Учебная карта madharness-mini-go

`madharness-mini-go` — Go-порт учебного минималистичного harness для курса,
книги и лабораторных работ по harness-инженерии кодирующих ИИ-агентов. Код
развивается по веткам: каждая ветка фиксирует одну главу и даёт студенту
состояние harness, которое можно читать, запускать, ломать и улучшать.

## Как пользоваться

1. Переключитесь на нужную ветку.
2. Прочитайте `README.md` этой ветки.
3. Откройте `LABS.md` и выберите задачу нужного уровня.
4. Используйте `docs/README.md` как локальный справочник по документации ветки.
5. После правки запускайте тесты и смотрите трассу.

```bash
git switch 03-Context-Layer
go test ./...
```

## Формат лабораторных

В каждой ветке `LABS.md` делится на три уровня:

- лёгкий уровень: маленькие задачи для чтения кода и точечной правки;
- средний уровень: задачи, которые меняют поведение текущего механизма;
- продвинутый уровень: задачи с архитектурным выбором и заметным компромиссом.

В каждом уровне по 2 задачи.

Каждая задача описывает:

- цель;
- задание;
- ограничения;
- критерий готовности;
- проверку или вопросы после выполнения.

## Рекомендуемый ритм занятия

1. Коротко разобрать `README.md` ветки.
2. Ознакомиться с основным потоком работы harness в `docs/code-overview.md`.
3. Выбрать одну лёгкую задачу всем студентам.
4. Дать средний или продвинутый уровень как самостоятельную работу.
5. В конце сравнить трассы: какие обращения к модели, вызовы инструментов и
   ограничения были реально задействованы.

## Проверка проекта

Во всех ветках базовая команда проверки одна:

```bash
go test ./...
```

Если конкретная лабораторная требует ручной проверки CLI, укажите это в своём
`LABS.md`. Для Go-порта ручная проверка обычно выглядит так:

```bash
go run ./cmd/madharness-mini ask "Объясни, что делает этот проект"
go run ./cmd/madharness-mini trace <trace-id>
```
