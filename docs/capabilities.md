# Возможности ветки

`02-AGENTS-md` расширяет минимальный harness двумя идеями:

- модель получает правила проекта из `AGENTS.md`;
- модель может попросить инструмент `read_image`, если vision input включён в
  конфиге.

## Команды CLI

| Команда | Что делает |
| --- | --- |
| `madharness-mini init` | Создаёт или обновляет `.madharness-mini/config.json`. |
| `madharness-mini ask "..."` | Отправляет один запрос модели без инструментов, но уже с учётом `AGENTS.md`. |
| `madharness-mini run "..."` | Запускает агентский цикл с инструментами workspace. |
| `madharness-mini trace <id>` | Показывает краткую сводку JSONL-трассы. |

При локальной разработке команда запускается как `go run ./cmd/madharness-mini`.

## Инструменты режима `run`

| Инструмент | Что делает |
| --- | --- |
| `list_files` | Показывает файлы workspace без служебных каталогов. |
| `read_file` | Читает UTF-8 фрагмент файла. |
| `read_image` | Проверяет локальное изображение и, если можно, прикрепляет его к следующему запросу модели. |
| `write_file` | Полностью перезаписывает UTF-8 файл. |
| `apply_patch` | Применяет точечные файловые правки. |
| `search_code` | Ищет буквальную подстроку в проекте. |
| `run_shell` | Запускает одну безопасно разобранную команду. |

## Конфигурация

Настройки лежат в `.madharness-mini/config.json`, `.env` или переменных
окружения `MADHARNESS_MINI_*`.

| Поле | Смысл |
| --- | --- |
| `model` | Имя модели для OpenAI-совместимого API. |
| `base_url` | Адрес API, обычно заканчивается на `/v1`. |
| `api_key` | Ключ доступа к провайдеру. |
| `temperature` | Температура model call. |
| `max_turns` | Максимальное число ходов в `run`. |
| `workspace_root` | Корень проекта, доступный инструментам. |
| `protected_paths` | Пути, которые инструменты не должны читать или менять. |
| `allow_shell` | Разрешён ли инструмент `run_shell`. |
| `supports_image_input` | Разрешает `read_image` передавать изображение модели. |
| `max_image_bytes` | Ограничивает размер файла изображения. |
| `image_detail` | Передаётся в мультимодальный payload как detail. |

Если `supports_image_input=false`, `read_image` возвращает только метаданные.
Это нужно, чтобы пользователь явно выбрал модель, которая умеет работать с
изображениями.

## Проектные инструкции

`AGENTS.md` читается только из корня workspace. Текст добавляется в system
prompt после встроенных правил harness. Лимит размера защищает prompt от
случайно огромных инструкций.

В этой ветке ещё нет отдельного `ContextManager`: prompt собирается прямо в
`internal/agent`. Это важная учебная точка, потому что следующая ветка покажет,
почему такую сборку полезно вынести в отдельный слой.

## Безопасность и трассы

`policy.SafePath()` не даёт файловым инструментам выйти за workspace и
блокирует защищённые пути. `read_image` не пишет base64 изображения в
observation и JSONL-трассу: бинарные данные прикрепляются только к следующему
model request, когда `supports_image_input=true`.

Каждый запуск пишет JSONL-файл в `.madharness-mini/traces`. Команда `trace`
показывает короткую сводку, чтобы студент мог сопоставить финальный ответ
агента с его реальными действиями.
